STEP --> 2 ->> POSITIONAL ENCODING 
            example -> the cat chased dog 
                       the dog chased cat 
            in this both gonna have the same vector embedding and deliver same meaning as well 

            so position encoding add some data about the position of the tokens 

            Positional encoding does not replace word embeddings. It adds position information to them.

            Example
                Sentence: "I love AI"
                Token	Position	Input to Transformer
                I	0	Embedding(I) + PE(0)
                love	1	Embedding(love) + PE(1)
                AI	2	Embedding(AI) + PE(2)

In one line: Positional embedding provides information about the position of each token so the Transformer can understand word order and sequence structure.
